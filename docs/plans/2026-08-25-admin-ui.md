# Admin UI Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development to implement this plan task-by-task.

**Goal:** Provide administrators with complete web management for users, pending registrations, and groups while retaining the CLI only for bootstrap and recovery.

**Architecture:** Add an administrator capability to the authenticated state response, then expose admin-only routes within the existing settings router. Keep API types and calls in a dedicated service and split the UI into Users, Pending, and Groups views. Server middleware remains the security boundary; the UI only hides unavailable navigation and handles authentication/elevation errors.

**Tech Stack:** Go, React 19, TypeScript, Material UI, Axios, Vitest, Testing Library.
